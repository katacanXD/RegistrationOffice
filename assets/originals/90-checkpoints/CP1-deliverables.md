## Ключевые результаты CP1

1. Определена цель проекта в формате SMART.
2. Описаны 4 персоны пользователей (пациент, врач, регистратор, администратор).
3. Сформулировано 16 user stories, приоритизированных по MoSCoW.
4. Построена User Story Map с разбивкой на релизы.
5. Выявлено 10 рисков с мерами снижения.
6. Составлена WBS с критическим путём.
7. Проведена оценка реализуемости — проект реализуем.
