## Пациент

| ID    | User Story                                                                                            | Приоритет |
|-------|-------------------------------------------------------------------------------------------------------|-----------|
| US-P1 | Как пациент, я хочу видеть доступные слоты врача, чтобы выбрать удобное время для записи.             | Must      |
| US-P2 | Как пациент, я хочу записаться на приём, чтобы получить медицинскую помощь.                           | Must      |
| US-P3 | Как пациент, я хочу отменить свою запись, чтобы освободить слот для другого пациента.                 | Must      |
| US-P4 | Как пациент, я хочу перенести свою запись на другой свободный слот, чтобы не терять место.            | Should    |
| US-P5 | Как пациент, я хочу видеть историю своих записей (прошедших и предстоящих), чтобы отслеживать визиты. | Could     |

## Врач

| ID    | User Story                                                                                           | Приоритет |
|-------|------------------------------------------------------------------------------------------------------|-----------|
| US-D1 | Как врач, я хочу видеть своё расписание на день/неделю, чтобы планировать работу.                    | Must      |
| US-D2 | Как врач, я хочу видеть список записанных пациентов на каждый слот, чтобы подготовиться к приёму.    | Must      |
| US-D3 | Как врач, я хочу видеть статус записи (booked/canceled/completed), чтобы знать актуальную ситуацию.  | Should    |

## Регистратура

| ID    | User Story                                                                                                | Приоритет |
|-------|-----------------------------------------------------------------------------------------------------------|-----------|
| US-R1 | Как регистратор, я хочу записывать пациента на свободный слот любого врача, чтобы обслуживать обращения.  | Must      |
| US-R2 | Как регистратор, я хочу переносить запись пациента на другой слот, чтобы обрабатывать просьбы о переносе. | Must      |
| US-R3 | Как регистратор, я хочу отменять запись с указанием причины, чтобы вести учёт отмен.                      | Must      |
| US-R4 | Как регистратор, я хочу видеть загрузку всех врачей, чтобы распределять пациентов равномерно.             | Should    |
| US-R5 | Как регистратор, я хочу получать предупреждение при попытке двойного бронирования, чтобы избежать ошибок. | Must      |

## Администратор

| ID    | User Story                                                                                                     | Приоритет |
|-------|----------------------------------------------------------------------------------------------------------------|-----------|
| US-A1 | Как администратор, я хочу настраивать рабочие интервалы и перерывы врачей, чтобы формировать сетку расписания. | Must      |
| US-A2 | Как администратор, я хочу видеть отчёт утилизации по врачу/дате/специальности, чтобы оптимизировать загрузку.  | Must      |
| US-A3 | Как администратор, я хочу экспортировать отчёт в CSV, чтобы проводить внешний анализ.                          | Must      |
| US-A4 | Как администратор, я хочу управлять справочниками врачей и пациентов, чтобы поддерживать актуальность данных.  | Should    |
| US-A5 | Как администратор, я хочу импортировать расписание и записи через CSV, чтобы массово загружать данные.         | Should    |
