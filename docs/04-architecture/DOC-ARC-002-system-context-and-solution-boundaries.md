## Контекстная диаграмма (текстовое описание)

### Система: RegistrationOffice

Центральная система управления расписанием врачей.

### Внешние акторы

| Актор           | Взаимодействие с системой                                    |
|-----------------|--------------------------------------------------------------|
| Пациент         | Просмотр расписания, запись, отмена, перенос (через веб-UI)  |
| Врач            | Просмотр своего расписания и списка пациентов (через веб-UI) |
| Регистратор     | Управление записями всех врачей (через веб-UI)               |
| Администратор   | Настройка расписания, отчёты, экспорт CSV (через веб-UI)     |

### Внешние системы (в перспективе)

| Система               | Назначение                               | Статус в MVP |
|------------------------|------------------------------------------|-------------|
| Городская запись (ЕМИАС)| Синхронизация расписания                | Не входит   |
| SMS/Email уведомления   | Напоминания пациентам                   | Не входит   |
| 1С: Медицина            | Обмен справочниками врачей/пациентов    | Не входит   |

## Границы MVP

### Входит в MVP

1. Управление справочниками (врачи, пациенты, специальности).
2. Настройка рабочих интервалов и перерывов.
3. Автогенерация слотов из интервалов.
4. Запись, отмена, перенос приёма.
5. 5 бизнес-валидаций.
6. Ролевая модель с JWT.
7. Отчёт утилизации + экспорт CSV.
8. Деплой на Yandex Cloud.

### Не входит в MVP

- Уведомления (SMS/email/push).
- Интеграция с внешними МИС.
- Мобильное приложение.
- Электронная медицинская карта.
- Оплата услуг.
- История болезни / диагнозы.

## Архитектура (высокоуровневая)

```
┌─────────────┐     ┌──────────────────────────────────────┐     ┌──────────────┐
│   Browser   │────▶│             Nginx (reverse proxy)    │────▶│  PostgreSQL  │
│  (React UI) │◀────│   Spring Boot API (REST + JWT)       │◀────│     DB       │
└─────────────┘     └──────────────────────────────────────┘     └──────────────┘
                                    │
                              Docker Compose
                              (Yandex Cloud)
```

### Компоненты

| Компонент      | Технология          | Назначение                        |
|----------------|---------------------|-----------------------------------|
| Frontend       | React, HTML, CSS    | Веб-интерфейс для всех ролей      |
| API Gateway    | Nginx               | Reverse proxy, маршрутизация       |
| Backend        | Spring Boot (Java)  | REST API, бизнес-логика, JWT       |
| Database       | PostgreSQL          | Хранение данных                    |
| Infrastructure | Docker Compose      | Оркестрация контейнеров            |
