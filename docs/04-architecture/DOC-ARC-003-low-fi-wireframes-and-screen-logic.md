## Набор экранов MVP

- Login / Registration
- Кабинет пациента
- Список врачей
- Календарь/слоты врача
- Карточка записи
- Админ-панель пользователей

## UI-правила

- все чувствительные действия подтверждаются;
- ошибки API отображаются человекочитаемо;
- обязательно есть loading/empty/error состояния.

## Навигация

- после login пользователь попадает в роль-специфичный кабинет;
- доступ к страницам ограничен по role-matrix;
- защищенные маршруты требуют валидный JWT-контекст.
