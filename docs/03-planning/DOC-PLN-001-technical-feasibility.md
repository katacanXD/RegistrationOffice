## Техническая реализуемость

| Критерий                        | Оценка    | Обоснование                                                   |
|---------------------------------|-----------|---------------------------------------------------------------|
| Backend (Spring Boot + JWT)     | Реализуемо| Команда имеет опыт работы с Java и Spring Boot                |
| Frontend (React)                | Реализуемо| Лукьянов имеет опыт frontend-разработки                       |
| БД (PostgreSQL)                 | Реализуемо| Стандартная СУБД, хорошо документирована                       |
| Docker + Nginx                  | Реализуемо| Стандартные инструменты контейнеризации                        |
| JWT-аутентификация              | Риск      | Требует дополнительного изучения Spring Security               |
| Генерация слотов из интервалов  | Реализуемо| Алгоритмически несложная задача                                |
| Отчёт утилизации + CSV экспорт  | Реализуемо| SQL-агрегация + стандартный экспорт                            |

## Организационная реализуемость

| Критерий                          | Оценка    | Обоснование                                              |
|-----------------------------------|-----------|----------------------------------------------------------|
| Команда (5 человек)               | Достаточно| Покрыты все ключевые роли (PM, backend, frontend, design)|
| Сроки (2 месяца)                  | Реалистично| При соблюдении WBS и приоритизации Must-функций          |
| Инструменты (GitVerse, Docker)    | Доступно  | Бесплатные или уже доступные инструменты                  |
| Деплой (Yandex Cloud)             | Реализуемо| Требуется аренда виртуальной машины                       |

## Вывод

Проект реализуем в заданные сроки при условии фокусировки на Must-функциональности (11 user stories) и параллельной работы backend/frontend. Основной технический риск — настройка JWT-аутентификации; для его снижения предусмотрено раннее прототипирование.
