## Подготовка к демо

1. Убедиться, что сервер запущен и доступен по адресу http://registration-office.ru/api.
2. В системе должны быть предзагружены: ≥ 3 врача, ≥ 5 пациентов, ≥ 100 слотов, ≥ 50 записей.
3. Подготовить учётные записи для каждой роли (admin, doctor, registrar, patient).

---

## Шаг 1: Аутентификация (2 мин)

1. Показать форму входа.
2. Войти как **администратор**.
3. Продемонстрировать получение JWT-токена.
4. Показать, что без токена API возвращает 401.

## Шаг 2: Управление расписанием (3 мин)

1. Войти как **администратор**.
2. Создать рабочий интервал для врача: дата, время 09:00–17:00, слот 30 мин, перерыв 13:00–14:00.
3. Показать, что слоты автоматически сгенерированы (за вычетом перерыва).
4. Продемонстрировать импорт расписания через CSV.
5. Повторно загрузить тот же CSV → показать идемпотентность (0 новых записей).

## Шаг 3: Запись на приём (3 мин)

1. Войти как **пациент** (или регистратор).
2. Выбрать врача и дату.
3. Просмотреть доступные слоты.
4. Записаться на свободный слот → показать подтверждение.
5. Попытаться записаться на тот же слот повторно → показать ошибку (двойное бронирование).
6. Попытаться записаться на время перерыва → показать ошибку.

## Шаг 4: Перенос и отмена (2 мин)

1. Перенести запись на другой свободный слот → показать, что старая запись отменена, новая создана.
2. Отменить запись с указанием причины → показать изменение статуса на canceled.

## Шаг 5: Просмотр расписания врача (1 мин)

1. Войти как **врач**.
2. Показать расписание на день: список слотов с информацией о записанных пациентах.

## Шаг 6: Отчёт утилизации (3 мин)

1. Войти как **администратор**.
2. Открыть отчёт «Загрузка расписания».
3. Показать фильтрацию: по врачу, по дате, по специальности.
4. Показать метрики: slots_total, slots_booked, slots_canceled, utilization %.
5. Экспортировать отчёт в CSV → открыть файл, показать формат.

## Шаг 7: Разграничение ролей (1 мин)

1. Войти как **пациент**.
2. Попытаться открыть отчёт утилизации → показать 403 Forbidden.
3. Показать, что пациент может управлять только своими записями.
