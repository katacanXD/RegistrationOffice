## DFD уровня 1 (декомпозиция)

### Процессы

| №  | Процесс                      | Входные потоки                           | Выходные потоки                    | Хранилище          |
|----|-------------------------------|------------------------------------------|------------------------------------|--------------------|
| P1 | Аутентификация                | Логин + пароль                           | JWT-токен / ошибка                 | D1: users, roles   |
| P2 | Управление расписанием        | Рабочие интервалы, параметры слотов      | Сетка слотов                       | D2: work_slots     |
| P3 | Просмотр доступных слотов     | Запрос (врач, дата)                      | Список свободных слотов            | D2, D3             |
| P4 | Запись на приём                | Выбранный слот + данные пациента         | Подтверждение / ошибка             | D3: appointments   |
| P5 | Отмена записи                 | ID записи + причина                      | Подтверждение отмены               | D3: appointments   |
| P6 | Перенос записи                | ID записи + новый слот                   | Подтверждение переноса             | D3: appointments   |
| P7 | Формирование отчёта           | Параметры фильтра (период, врач, спец.)  | Отчёт утилизации / CSV            | D2, D3             |

### Хранилища данных

| ID | Хранилище     | Содержание                                  |
|----|---------------|---------------------------------------------|
| D1 | users, roles  | Учётные записи и роли                       |
| D2 | work_slots    | Рабочие интервалы врачей                    |
| D3 | appointments  | Записи на приём                             |
| D4 | doctors       | Справочник врачей                           |
| D5 | patients      | Справочник пациентов                        |

### Потоки данных между процессами

- P3 → P4: список свободных слотов используется при записи.
- P4 → P5: созданная запись может быть отменена.
- P4 → P6: созданная запись может быть перенесена (отмена + новая запись).
- P2 → P3: сетка слотов определяет, какие временные позиции доступны.
- P3, P4, P5, P6 → P7: данные о слотах и записях агрегируются в отчёт.
