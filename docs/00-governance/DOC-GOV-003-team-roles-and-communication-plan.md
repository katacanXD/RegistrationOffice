## Правила работы

1. **Ветвление**: каждая задача выполняется в отдельной ветке вида `feature/название-задачи`.
2. **Pull Request**: любой код мерджится только через PR с ревью минимум 1 участника.
3. **Коммиты**: осмысленные сообщения на русском или английском языке.
4. **Стендапы**: краткая синхронизация в чате перед каждым рабочим спринтом.
5. **Документация**: обновляется параллельно с кодом; каждый CP сопровождается актуализацией docs.
6. **Дедлайны**: задачи фиксируются с датой завершения; просрочка обсуждается на ближайшем стендапе.

## Процесс работы с задачами

1. Задача создаётся в трекере YouGile.
2. Назначается ответственный.
3. Ответственный создаёт ветку и работает над задачей.
4. По готовности — PR с описанием изменений.
5. Ревью + мердж в master.
6. Обновление документации при необходимости.
