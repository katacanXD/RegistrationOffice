## Правила работы

1. **Ветвление**: каждая задача выполняется в отдельной ветке вида `подгуппа-задачи/название-задачи`.
2. **Pull Request**: любой код мерджится только через PR в ветку `dev` с ревью минимум 1 участника.
3. **master**: ветка `master` используется только для финальных версий после CP4; промежуточные срезы — в `dev`.
4. **Коммиты**: осмысленные сообщения на русском или английском языке.
5. **Стендапы**: краткая синхронизация в чате перед каждым рабочим спринтом.
6. **Документация**: обновляется параллельно с кодом; каждый CP сопровождается актуализацией docs.
7. **Дедлайны**: задачи фиксируются с датой завершения; просрочка обсуждается на ближайшем стендапе.

## Процесс работы с задачами

1. Задача создаётся в трекере YouGile.
2. Назначается ответственный.
3. Ответственный создаёт ветку и работает над задачей.
4. По готовности — PR с описанием изменений.
5. Ревью + мердж в dev.
6. Обновление документации при необходимости.
