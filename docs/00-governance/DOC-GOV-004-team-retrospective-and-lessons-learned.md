## Критический путь

Задачи критического пути определяются связями: 1.1 → 1.4 → 2.2 → 3.1 → 3.5 → 4.1 → 4.2 → 4.4 → 4.5.

Обоснование: проектирование API зависит от модели данных, которая зависит от BPMN-процессов, которые основаны на user stories. Реализация frontend зависит от backend API. Тестирование и деплой — завершающие этапы.
