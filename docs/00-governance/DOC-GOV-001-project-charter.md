## 4. Цель проекта

Создать к 01.05.2026 MVP-сервис управления расписанием врачей: запись, перенос, отмена приёмов; автоматический расчёт утилизации расписания (цель ≥ 75%).

## 5. Проблема

«Окна» в расписании, двойное бронирование, ручные ошибки при переносе/отмене, отсутствие отчётности по загрузке врачей.

## 6. Задачи

1. Смоделировать расписание врачей (интервалы, слоты, перерывы).
2. Реализовать запись/перенос/отмену.
3. Обеспечить 5+ бизнес-валидаций.
4. Построить отчёт утилизации с экспортом CSV.
5. Реализовать JWT-аутентификацию и 4 роли.

## 7. KPI

| Метрика                | Формула                           | Цель    |
|------------------------|-----------------------------------|---------|
| Утилизация             | booked / total × 100%             | ≥ 75%   |
| Доля отмен             | canceled / booked × 100%          | ≤ 15%   |
| Время отчёта           | генерация отчёта                  | ≤ 3 сек |
| Валидации              | количество                        | ≥ 5     |
| Данные                 | слоты / записи                    | ≥100/≥50|

## 11. Границы

Входит: расписание, запись/перенос/отмена, отчёт + CSV, JWT, 4 роли.
Не входит: интеграция с МИС, реальные данные, мобильное приложение, оплата.

## 12. Критерии приёмки

1. Полный цикл записи/переноса/отмены работает.
2. 5+ валидаций (двойное бронирование, интервал, перерыв, статус, FK).
3. Отчёт утилизации по врачу/дате/специальности.
4. Экспорт CSV: doctor_id, date, slots_total, slots_booked, utilization.
5. ≥ 100 слотов, ≥ 50 записей обработаны.
6. Деплой на http://registration-office.ru/api.
