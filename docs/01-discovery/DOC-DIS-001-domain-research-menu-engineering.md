## Контекст предметной области

Управление расписанием врачей — ключевой процесс медицинского учреждения. Расписание определяет доступность врачей для пациентов и непосредственно влияет на качество медицинского обслуживания и экономическую эффективность учреждения.

Типичные проблемы в существующих процессах:

- «Окна» в расписании (пустые слоты между приёмами) из-за ручного планирования.
- Двойное бронирование при параллельной работе нескольких регистраторов.
- Отсутствие контроля перерывов — пациенты записываются на время обеда врача.
- Неравномерная загрузка — у одних врачей очередь, у других пустое расписание.
- Отсутствие прозрачной отчётности для принятия управленческих решений.

## Основные понятия

| Термин            | Определение                                                             |
|-------------------|-------------------------------------------------------------------------|
| Слот              | Минимальная единица расписания, отведённая под один приём                |
| Рабочий интервал  | Временной отрезок (start_time – end_time) в пределах одного рабочего дня|
| Перерыв           | Временной отрезок внутри рабочего интервала, недоступный для записи      |
| Утилизация        | Доля занятых слотов от общего числа доступных слотов за период           |
| Запись (приём)     | Резервирование конкретного слота за пациентом                           |
| Перенос           | Отмена текущей записи и создание новой на другой свободный слот         |

## Аналоги и существующие решения

- МИС (медицинские информационные системы): ЕМИАС, «Медиалог», «Инфоклиника».
- Порталы госуслуг: запись через портал «Госуслуги» / региональные порталы.
- Отличие данного проекта: акцент на метрике утилизации и управлении «окнами» расписания.

## Выгода от реализации

1. Повышение утилизации расписания (меньше пустых слотов).
2. Снижение количества «окон» за счёт контролируемой записи/переноса.
3. Снижение ошибок за счёт валидаций (двойное бронирование, перерывы, статусы).
4. Прозрачная отчётность для управленческих решений.
5. Ускорение работы регистратуры и улучшение клиентского опыта.
