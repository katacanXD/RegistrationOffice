## Персона 1: Пациент

| Поле               | Значение                                                              |
|--------------------|-----------------------------------------------------------------------|
| Имя                | Иванов Алексей Петрович                                               |
| Возраст            | 35 лет                                                                |
| Роль               | Пациент                                                               |
| Описание           | Работающий человек, нуждающийся в медицинской помощи. Ценит удобство и скорость записи. Предпочитает записываться онлайн, а не звонить в регистратуру. |
| Цели               | Быстро найти свободного врача нужной специальности; записаться на удобное время; при необходимости перенести или отменить запись. |
| Боли               | Долгое ожидание на линии; отсутствие информации о свободных слотах; невозможность перенести запись без звонка. |

## Персона 2: Врач

| Поле               | Значение                                                              |
|--------------------|-----------------------------------------------------------------------|
| Имя                | Смирнова Елена Владимировна                                           |
| Возраст            | 42 года                                                               |
| Роль               | Врач-терапевт                                                         |
| Описание           | Опытный врач поликлиники. Ведёт приём по расписанию. Хочет видеть своё расписание на день/неделю и знать, кто записан. |
| Цели               | Видеть актуальное расписание; знать список записанных пациентов; не быть перегруженной сверх рабочего графика. |
| Боли               | Пациенты записываются на время перерыва; «окна» между приёмами; не знает заранее, сколько пациентов будет. |

| Поле               | Значение                                                              |
|--------------------|-----------------------------------------------------------------------|
| Имя                | Козлова Мария Сергеевна                                               |
| Возраст            | 28 лет                                                                |
| Роль               | Сотрудник регистратуры                                                |
| Описание           | Принимает звонки и записывает пациентов. Управляет записями всех врачей. Работает в условиях многозадачности. |
