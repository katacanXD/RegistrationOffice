## Что сработало

- ранняя фиксация ролевой модели;
- единый стек backend (Spring + PostgreSQL + JWT);
- контейнеризация с воспроизводимым запуском.

## Что улучшить

- раньше согласовывать API-контракты с frontend;
- формализовать UI state-модель для ошибок/пустых состояний;
- автоматизировать регресс ключевых сценариев записи на прием.

## Договоренности на следующий цикл

- сначала обновляем docs, затем кодовые изменения в спорных областях;
- на каждую роль минимум 1 end-to-end сценарий;
- все изменения в доступах сверяются с `SecurityConfig` и документацией.
