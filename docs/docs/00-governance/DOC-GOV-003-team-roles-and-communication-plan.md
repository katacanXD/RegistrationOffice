# DOC-GOV-003 Команда и план коммуникации

| Версия | Статус | Дата обновления |
|---|---|---|
| v1.0 | Draft | 2026-04-01 |

## Роли

| Код роли | Ответственность |
|---|---|
| Lead | приоритизация, синхронизация артефактов и контроль scope |
| Backend | API, безопасность, БД, миграции |
| Frontend | UI/UX, интеграция с API, клиентская валидация |
| QA | приемочные сценарии, регресс, тестовая отчетность |
| DevOps | контейнеризация, окружения, деплой, мониторинг |

## Каналы коммуникации

- ежедневный sync: 15 минут;
- еженедельный planning/review;
- отдельный поток по API-контрактам frontend/backend;
- протокол решений в документах `docs/docs`.

## Правила

- change request фиксируется в задачах и в документации;
- любое изменение endpoint/DTO синхронизируется между frontend и backend в течение 1 рабочего дня;
- релиз без обновленного runbook и smoke-checklist не допускается.
