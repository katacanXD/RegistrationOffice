## Основной процесс: запись на прием

1. Пользователь входит в систему.
2. Пациент открывает список врачей.
3. Пациент выбирает врача и дату.
4. Система показывает свободные слоты.
5. Пациент создает запись.
6. Система возвращает подтверждение.

## Альтернативные ветки

- перенос записи;
- отмена записи;
- создание записи регистратором от имени пациента.

## Flow по ролям

- `patient`: поиск, запись, управление своими записями;
- `doctor`: календарь и расписание;
- `registrar`: поиск пациентов, управление записями;
- `admin`: управление пользователями/ролями.
