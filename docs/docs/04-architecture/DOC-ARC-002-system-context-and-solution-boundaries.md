| Версия | Статус | Дата обновления |
|---|---|---|
| v1.0 | Draft | 2026-04-01 |

## Компоненты решения

- Frontend SPA (web UI)
- Backend API (Spring Boot)
- PostgreSQL
- Nginx reverse proxy

## Внешние акторы

- Пациент
- Врач
- Регистратор
- Администратор

## Границы MVP

Внутри границ:
- авторизация;
- управление пользователями;
- расписание и слоты;
- записи на прием.

Вне границ:
- интеграции с гос.системами;
- мобильные приложения;
- платежи и страховые расчеты.
