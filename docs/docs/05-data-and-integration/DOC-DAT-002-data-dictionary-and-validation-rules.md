# DOC-DAT-002 Словарь данных и правила валидации

| Версия | Статус | Дата обновления |
|---|---|---|
| v1.0 | Draft | 2026-04-01 |

## Пользователь (`t_users`)

- `f_login`: уникальный логин, обязателен
- `f_fio`: ФИО, обязательно
- `f_password`: хэш пароля, обязателен
- `f_policy_number`: номер полиса (опционально)
- `f_role_id`: ссылка на роль, обязательна
- `f_speciality_name`: специальность (для врача)

## Слот (`t_work_slots`)

- `f_doctor_id`: врач, обязателен
- `f_date`: дата слота
- `f_start_time`, `f_end_time`: границы интервала
- `f_slot_minutes`: длина слота
- `f_break_start`, `f_break_end`: перерыв (опционально)

## Запись (`t_appointments`)

- `f_doctor_id`: врач
- `f_patient_id`: пациент
- `f_slot_datetime`: дата/время
- `f_status_id`: статус записи

## Правила

- отмененная запись не должна считаться доступным приемом;
- запись может создавать только авторизованный пользователь с нужной ролью;
- frontend валидирует форму, backend выполняет окончательную валидацию.
