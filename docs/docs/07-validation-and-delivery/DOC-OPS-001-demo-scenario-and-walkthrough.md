## Цель демо

Показать полный пользовательский поток через frontend с подтверждением backend-результата.

## Сценарий демо

1. Login под ролью `patient`.
2. Показ списка врачей.
3. Запись на слот.
4. Просмотр созданной записи.
5. Logout.

## Дополнительный блок

- Login как `registrar` и создание записи для пациента;
- Login как `admin` и управление пользователем.
