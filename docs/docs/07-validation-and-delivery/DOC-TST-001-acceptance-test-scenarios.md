# DOC-TST-001 Приемочные сценарии

| Версия | Статус | Дата обновления |
|---|---|---|
| v1.0 | Draft | 2026-04-01 |

## Сценарий 1: Пациент записывается на прием

- Предусловие: пользователь авторизован как `patient`.
- Шаги: выбрать врача -> выбрать слот -> подтвердить запись.
- Ожидаемо: создана запись со статусом `booked`.

## Сценарий 2: Пациент отменяет свою запись

- Предусловие: у пациента есть активная запись.
- Шаги: открыть запись -> отменить.
- Ожидаемо: статус записи изменен на `canceled`.

## Сценарий 3: Регистратор создает запись за пациента

- Предусловие: роль `registrar`.
- Шаги: найти пациента -> выбрать врача и слот -> создать запись.
- Ожидаемо: запись создается успешно.

## Сценарий 4: Админ управляет пользователями

- Предусловие: роль `admin`.
- Шаги: открыть список пользователей -> изменить роль/данные.
- Ожидаемо: изменения применены и доступны в API.
