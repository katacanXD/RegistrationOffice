# Исходный кейс: цифровая медицинская регистратура

| Версия | Статус | Дата обновления |
|---|---|---|
| v1.0 | Active | 2026-04-01 |

## Постановка задачи

Смоделировать и реализовать MVP системы регистрации пациентов на прием с разделением доступа по ролям.

## Роли

- `patient`
- `doctor`
- `registrar`
- `admin`

## Базовые требования

- регистрация и вход;
- просмотр профиля;
- управление пользователями (для admin/registrar);
- просмотр врачей и слотов;
- создание, изменение и отмена записей.

## Ограничения MVP

- только web frontend + backend API;
- без мобильных приложений;
- без интеграции с гос.медсистемами;
- без биллинга/страховых расчетов.

## Нефункциональные требования

- защищенный доступ (JWT + роли);
- предсказуемые API-контракты;
- воспроизводимый деплой через Docker Compose.

## Критерии приемки

- ключевые пользовательские сценарии проходят end-to-end;
- документация синхронизирована с реализацией;
- система поднимается по runbook на VM.
