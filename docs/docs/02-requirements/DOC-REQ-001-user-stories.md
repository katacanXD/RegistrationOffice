## Patient

- Как `patient`, я хочу увидеть список врачей, чтобы выбрать подходящего специалиста.
- Как `patient`, я хочу записаться на свободный слот, чтобы получить прием.
- Как `patient`, я хочу отменить или перенести запись, чтобы управлять своим временем.

## Doctor

- Как `doctor`, я хочу видеть календарь своих слотов, чтобы планировать приемы.
- Как `doctor`, я хочу видеть расписание по дате, чтобы подготовиться к рабочему дню.

## Registrar

- Как `registrar`, я хочу находить пациента по параметрам поиска, чтобы быстро помочь с записью.
- Как `registrar`, я хочу создавать запись от имени пациента, чтобы обслуживать офлайн-обращения.

## Admin

- Как `admin`, я хочу управлять пользователями и их ролями, чтобы контролировать доступ.
- Как `admin`, я хочу удалять неактуальные аккаунты, чтобы поддерживать порядок.

## Нефункциональные требования (MVP)

- JWT-аутентификация и role-based access.
- Консистентные API-контракты для frontend.
- Воспроизводимый деплой через Docker Compose.
