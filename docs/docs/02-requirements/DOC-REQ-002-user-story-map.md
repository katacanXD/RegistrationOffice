## Backbone

1. Авторизация
2. Профиль и пользователи
3. Врачи и слоты
4. Записи на прием
5. Администрирование

## MVP slices

### Slice A: Доступ
- registration/login/logout/refresh
- получение `me`

### Slice B: Базовые кабинеты
- список врачей
- просмотр слотов врача
- запись пациента

### Slice C: Операции с записями
- просмотр краткой/детальной записи
- отмена и обновление записи

### Slice D: Администрирование
- поиск пользователей
- изменение роли/данных
- удаление пользователя

## Фокус frontend

Для каждого slice нужен экран, состояние загрузки, состояние ошибки и пустое состояние данных.
