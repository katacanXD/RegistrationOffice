## Стек MVP

- Backend: Java 21, Spring Boot, JPA, Security, JWT.
- DB: PostgreSQL 16.
- Infra: Docker Compose + Nginx.
- Frontend: веб SPA (технология уточняется на этапе CP2).

## Вывод по реализуемости

Решение реализуемо в учебном/пилотном контуре при условии:
- стабилизации API-контрактов до активной frontend-разработки;
- фиксации role-matrix и правил доступа;
- автоматизации smoke-проверок после деплоя.

## Технические риски

- рассинхрон DTO между backend и frontend;
- ошибки в календарной логике слотов;
- нехватка e2e-покрытия для ключевых ролей.
