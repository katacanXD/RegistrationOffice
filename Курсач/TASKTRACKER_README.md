# 📊 Task Tracker для RegistrationOffice

Этот файл содержит полный список всех задач проекта `RegistrationOffice`, отмечены статусы выполнения, распределение по спринтам и приоритеты.

## 📁 Файлы

- **TASKTRACKER.csv** — основной трекер в формате CSV (совместим с Excel, Google Sheets, Notion)
- **таски.txt** — исходный файл в текстовом формате с дополнительной информацией

## 🔍 Колонки в CSV

| Колонка | Описание |
|---------|---------|
| **ID** | Уникальный номер задачи (1–105) |
| **Категория** | Категория (DevOps, Frontend, Backend, Security, etc.) |
| **Название задачи** | Краткое название (англ. формат для поиска) |
| **Профессиональная формулировка** | Полное описание задачи на русском |
| **Исполнитель** | Кто отвечает (Katacan, Илья, Daniil, Karim, George) |
| **Статус** | Статус выполнения (Готово / В процессе / TODO) |
| **Спринт** | Спринт (0=подготовка, 1–4=основные спринты) |
| **Приоритет** | Важность (Высокий / Средний / Низкий) |

## 💡 Как использовать

### Вариант 1: Google Sheets
1. Откройте Google Sheets
2. Наведите на меню → **Файл** → **Импортировать**
3. Загрузите **TASKTRACKER.csv**
4. Разделите по столбцам (Data → Split text to columns)
5. Добавьте фильтры и условное форматирование

### Вариант 2: Excel
1. Откройте Excel
2. **Файл** → **Открыть** → выберите **TASKTRACKER.csv**
3. Задайте кодировку: UTF-8
4. Разделите текст по столбцам (Data → Text to Columns)

### Вариант 3: Notion
1. Создайте Database → Import → CSV
2. Загрузите файл
3. Настройте представления по категориям и спринтам

## 📋 Фильтры и сортировка

Рекомендуемые фильтры:
- **По статусу** — видеть только активные задачи
- **По исполнителю** — разделить личные таски
- **По спринту** — плани работу по неделям
- **По приоритету** — первым делать Высокие

## ✅ Статусы задач

- **Готово** ✓ — задача завершена
- **В процессе** ⏳ — ведётся работа
- **TODO** ◻️ — планируется в будущем
