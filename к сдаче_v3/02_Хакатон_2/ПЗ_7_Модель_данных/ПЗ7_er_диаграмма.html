Правила данных

П1. Логин не повторяется.
П2. Роль — из допустимого перечня.
П3. Статус — booked / canceled / completed.
П4. Хэш токена не повторяется.
П5. На пару «врач + время» — не больше одной активной записи.
П6. На пару «пациент + время» — не больше одной активной записи.
П7. Время записи входит в рабочий слот и не попадает в перерыв.
П8. У записи всегда есть врач, пациент и статус.
П9. У операции всегда есть запись; актор может быть пустым; причина — если передана.
П10. Полис уникален — не реализовано, открытый вопрос.
П11. У врача есть хотя бы один слот — не гарантируется БД, открытый вопрос.
П12. Специальность — из справочника; сейчас свободная строка, открытый вопрос.
Роль и статус — атрибуты с допустимыми значениями; физически вынесены в t_dict_role и t_dict_status. Отчёт утилизации и свободные слоты вычисляются, отдельно не хранятся.
