# «К сдаче» — состав комплекта (v3)

**Проект:** RegistrationOffice — сервис записи на приём.
**Команда:** 1, ЭФБО-10-25.
**Дата комплекта:** 13.11.2026.
**Ветка:** `fix/review-v3` (от `submission-v3`, без merge в `master`).

Здесь лежит финальный комплект к сдаче. Исходные методички, пустые бланки и рабочие файлы остались в `3 семак`; старая сборка — в `к сдаче`. Файлы `*_v2` рядом с новыми оставлены как архив предыдущей версии — при сдаче можно игнорировать.

## Что изменилось в v3

- Собраны **оригинальные бланки** ПЗ 3, 4, 5, 6, 7 (структура преподавателя, а не пересобранные таблицы), заполнены по коду и документации.
- В ПЗ-3 добавлен **анализ конкурентов** (Д1–Д3): ЕМИАС, СберЗдоровье, НаПоправку, ПроДокторов, OpenEMR и текущий способ.
- Заполнены **протоколы самопроверки** ПЗ 3–7 (внутренняя проверка вместо соседней команды).
- Пересобраны по **ГОСТ 7.32–2017**: ГОСТ-отчёт, ПЗ №1 и ПЗ №2 (14 pt, 1,5 интервал, поля 30/15/20/20 мм, титул, реферат, содержание, список источников).
- Сделаны **три презентации**: отчёт по ГОСТ, защита Хакатона 1, защита Хакатона 2.
- Приложены сами ГОСТы (34.602–2020 и 24.104–2023).
- Все ключевые документы продублированы в PDF.

## Что осталось сделать вручную

1. Открыть презентации в PowerPoint на своём рабочем Office и один раз проверить шрифты/картинки (на этой машине PowerPoint не открывает файлы с изображениями — PDF-версии лежат рядом и проверены).
2. Проверить PDF: титулы, содержание, отсутствие обрезанных таблиц.
3. Прогнать триггеры на живом PostgreSQL (в тестах — H2).
4. Провести репетицию защиты 10 + 5 минут, подготовить резервные скриншоты/видео.
