## Откуда взялось ТЗ на первый хакатон

В `1 хаккатон/требования.md` написано только:

1. сдать все практические 3 и 4;
2. «плюс все госты с пояснительной запиской»;
3. отчёт по ГОСТ 7.32.

Отдельной строки «разработать ТЗ» там нет. Но в папке `1 хаккатон/ГОСТ/` лежат два стандарта:

- **ГОСТ 34.602–2020** — «Техническое задание на создание автоматизированной системы»;
- **ГОСТ 24.104–2023** — общие требования к АСУ.

Я истолковал фразу «все ГОСТы с пояснительной запиской» как комплект документов по этим ГОСТам: ТЗ по 34.602 + пояснительная записка по 7.32 + аналитический отчёт о нормативной базе. Поэтому ТЗ появилось как **производный документ**, а не как отдельно поставленная задача.

Если преподаватель имел в виду только теоретический отчёт о ГОСТах и ПЗ, ТЗ можно считать дополнительным документом: оно не заменяет ПЗ 3/4 и не конфликтует с ними. Если нужно — можно убрать его из обязательного списка и оставить как приложение.
